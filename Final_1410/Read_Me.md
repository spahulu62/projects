Instructions: 
The main.py file is where the game is. Running it should start up the game
loop. You can navigate by clicking buttons with your mouse. The control
screen tells you how to play. Everything is pretty straight forward and 
simple. Enjoy the Game.

Score File:
The score file only saves the TOP 5 scores and I think if two scores are
the same the newest has priority. If there is no file the score screen
will just tell you there is no scores yet. After completing a game and
saving your score the TOP 5 scores can be seen in the score screen.

Experience:
For this project I learned a bunch of new stuff. Honestly most of this 
project was learning as the project progressed. I think you can tell by
the structure and design of the code. If I ever make a game again I would
structure the entire thing differently. The first Half of the creation of
this game the designed fit really well. It was when I started adding more 
complex things into the code that it became what it is.
